# Programación II

Repositorio correspondiente a la materia **Programación II**, donde se almacenarán proyectos, ejercicios, prácticas y subproyectos relacionados con el desarrollo de software utilizando **Python, Django y Odoo**.

## 📚 Tecnologías

### 🐍 Python

**Python** es un lenguaje de programación de alto nivel, interpretado y de propósito general. Se caracteriza por tener una sintaxis sencilla y fácil de aprender.

En esta materia se utilizará para desarrollar ejercicios, programas y aplicaciones, además de servir como base para trabajar con Django y Odoo.

### 🌐 Django

**Django** es un framework web desarrollado en Python que permite crear aplicaciones y sitios web de manera rápida, organizada y segura.

Se utilizará para desarrollar proyectos web, trabajando con elementos como modelos, vistas, plantillas, formularios, usuarios y bases de datos.

### 🏢 Odoo

**Odoo** es una plataforma de gestión empresarial de código abierto desarrollada principalmente con Python. Cuenta con diferentes módulos para administrar procesos empresariales.

En esta materia se utilizará para conocer el desarrollo y personalización de módulos, modelos, vistas y funcionalidades dentro de Odoo.
